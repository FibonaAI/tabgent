## English

**Name:** Tabgent

**Short description:** Use Codex in Chrome to read pages, compare tabs and work with PDFs. Requires macOS, Codex and a local connector.

**Description:**

Your agent in every tab.

Tabgent lets you use Codex in the Chrome sidebar while you browse. Ask about the
page you're reading, compare information across open tabs, or ask Codex to fill
fields and search a website.

- Select text on a page and ask about it without copying and pasting.
- Read PDF text and diagrams, highlight passages and download annotated copies.
- Attach images, PDFs, DOCX documents or text files to a conversation.
- Find earlier conversations for the current page and switch between related chats.
- Send follow-up instructions while a task runs, steer it or stop it.
- Choose your model, reasoning effort, approval mode and browser window access.

Requirements: macOS, Chrome 142+, Python 3.9+, a compatible Codex installation and
the separate Tabgent connector. Install the connector using the setup page, then
return to Tabgent to check the connection and sign in to Codex if needed. Windows
and Linux are not currently supported. Codex access and usage limits apply.

Messages, requested page content, screenshots and relevant attachments are sent
through Codex to your configured service. Processing is not entirely local.
Tabgent has no separate cloud service processing your conversations.

Tabgent is an independent project, not affiliated with OpenAI or Google.

## 简体中文

**名称：** Tabgent

**简短说明：** 在 Chrome 中使用 Codex，阅读网页、比较标签页、处理 PDF。需要 macOS、Codex 和本地连接器。

**详细介绍：**

每个标签页，都有你的智能助手。

Tabgent 让你在 Chrome 侧边栏使用 Codex。可以针对当前网页提问，比较几个标签页的信息，也可以让它填写字段、操作网站搜索。

- 选中网页文字直接提问，不用复制粘贴。
- 阅读 PDF 文字和图表，高亮段落，下载带标注的文件。
- 上传图片、PDF、DOCX 或文本文件。
- 查看当前网页的历史对话，切换有关联的会话。
- 任务执行时补充要求、调整方向或停止。
- 选择模型、思考强度、批准方式和可以操作的浏览器窗口。

使用要求：macOS、Chrome 142+、Python 3.9+、兼容的 Codex，以及单独安装的 Tabgent 连接器。请按照设置页面安装连接器，再回到 Tabgent 检查连接；需要时会引导你登录 Codex。目前不支持 Windows 和 Linux。使用时受 Codex 账号权限和用量限制。

你的消息、任务需要的网页内容、截图和附件会通过 Codex 发送到所配置的服务，并非全部在本机处理。Tabgent 没有另外处理会话的云端服务。

Tabgent 是独立项目，并非 OpenAI 或 Google 的官方产品。
